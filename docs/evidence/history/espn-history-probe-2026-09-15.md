# ESPN WNBA history probe (2026-09-15)

Scope: about 380 GET requests from a local residential IP (not Cloudflare), run one at a time. No 403 or 429 responses. `site.api.espn.com` returned 200 locally, so the 403 is specific to CF egress. Headers: core `Cache-Control: max-age=900, stale-while-revalidate=7200` (Varnish); site.web summary `max-age=1`; both send `access-control-allow-origin: *`. No rate-limit headers were seen. ESPN publishes no API licence or terms for these JSON endpoints; recorded as a fact only.
`C = https://sports.core.api.espn.com/v2/sports/basketball/leagues/wnba`, `W = https://site.web.api.espn.com/apis`, `S = W/site/v2/sports/basketball/wnba`. Raw JSON and scripts (`p*.mjs`) are in this directory.

## Headline findings
- **Several endpoints ignore the season and quietly return current data.** Core `/seasons/{y}/teams/{id}/athletes`, `/seasons/{y}/athletes` (always 209), `/seasons/{y}/coaches`, site `standings?season=1997|1998` (returns the 2026 table) and team-season `venue` all do this. A 200 status proves nothing. `/seasons/{y}/teams/{id}` also returns 200 for teams that did not exist that year (e.g. 2026/15 Utah Starzz).
- **The per-season data you can trust** is player and team season stats (1997+), per-game data from summary and core events (2002+), playoff `series` and `notes` on scoreboard events (1999/2000+), standings (2003+), awards (1997+, incomplete) and draft rounds (2018+).
- **1997–2001 contain no game-level box or play-by-play.** You still get 1997+ player-season totals, league leaders (a full player list with `limit=500`) and 1998–2001 final scores.

## 1997–2002 detail (row 9)
- **1997:** 112 regular-season events and 0 postseason, all `STATUS_TBD` with no scores. Core status TBD, score undefined, no linescores, plays 0, officials 0. Summary gives team stats as 9 empty rows. **Nothing usable beyond schedule and matchups.**
- **1998:** 150 events (144 IN_PROGRESS, 4 FINAL, 2 FORFEIT). All have scores. **No postseason events.**
- **1999:** 216 events. Scores on 198 are correct (1999-09-05 HOU 59 NYL 47 = Finals G3). Status is `IN_PROGRESS`, `winner` undefined, core linescores = 2 halves. Competitor statistics return 404, roster 404, plays 0, box 0.
- **2000:** 300 events, 272 scored, 16 postseason with correct scores. Same status and box limitations.
- **2001:** 307 events, 273 scored. Some Finals games are TBD with no score (2001-09-02 CHA@LOS). No box or plays.
- **2002:** 257 regular-season FINAL events with `winner`. Summary has **play-by-play (355–360) and player box (11/11)** but **no team box**. Core competitor statistics return 404, but core competitor `roster` works (11). Standings are corrupt.
- Usable 1997–2001 sources: final scores 1998–2001 (derive winners yourself); player season totals, v3 career rows with teamId, leaders with `limit=500`, and awards (all 1997+).

## Suggested derivations (not ESPN-native)
- Season team set: team ids on regular-season scoreboard events, minus All-Star ids.
- Season rosters: 2002+ box-score athletes; 1997–2001 from v3 `stats` rows (teamId per season) for players found via leaders or awards.
- Franchise lineage (15→17, 10→18, 3 stable, 132052 shared between both Portland Fire eras) must be curated by hand.
- Standings for 1997–2002 must be computed from scores; 1997 and 1998 postseason must come from a non-ESPN source.
